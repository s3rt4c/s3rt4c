# Repository Instructions

- Write all public-facing content in professional English.
- Never invent achievements, certifications, vulnerabilities, experience, statistics, or project capabilities.
- Never expose credentials, API keys, passwords, tokens, flags, student IDs, or unnecessary personal identifiers.
- Maintain an offensive-security-focused professional identity.
- Prefer proof-of-work over buzzwords.
- Avoid excessive badges, animations, GitHub statistics, and hacker clichés.
- Keep technical writing concise and accurate.
- Preserve factual project history.
- Do not push directly to `main` without review.
- When factual information or a link is missing, use a clear placeholder instead of guessing.
