## Featured Projects

### [Network Security & Threat Analysis Platform](https://github.com/s3rt4c/neo4j_project)

**Python • Neo4j • FastAPI • React • TypeScript • Cytoscape.js**

This project grew out of work I first explored during my Cyberwise internship. I later rebuilt and extended the idea into a full-stack security analysis platform.

It turns network traffic and IDS data into a graph model that makes it easier to investigate relationships between endpoints, communications, and security events.

**Highlights**

- Graph-based modeling of endpoints and network relationships
- Traffic and IDS alert correlation
- FastAPI backend with a React/TypeScript investigation interface
- Interactive graph visualization with Cytoscape.js

[![View Repository](https://img.shields.io/badge/View%20Repository-Network%20Security%20Platform-21262D?style=for-the-badge&logo=github&logoColor=white)](https://github.com/s3rt4c/neo4j_project)

### [ThreatClock](https://github.com/s3rt4c/threatclock)

**Python • Apache Spark • Kafka • Threat Intelligence**

ThreatClock is an academic ransomware early-warning and risk-analysis prototype. It combines multiple external signals instead of looking at a single indicator in isolation.

The project explores how ransomware incidents, CVE information, news signals, and external data can be processed into a structured risk-analysis workflow.
